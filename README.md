# 钢铁绿色转型指标与副产物闭环

贯通精品钢生产、固废资源化、制氢和环保指标的可追溯数据链。

## 参与方与事实

主要参与方包括钢铁企业管理人员、车间操作人员、环保人员、固废处理企业、能源管理人员。领域资料记录以下已经确认的事实：

- 迁安钢铁产业推进减量提质和精品钢生产
- 当地企业在多道工序应用人工智能并达到绿色工厂标准
- 工业固废资源化和焦炉煤气制氢形成循环经济链条

## 业务约束

- 班次数据冻结
- 指标口径
- 副产物去向
- 职责分离
- 历史报表不可重写

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/steel_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
