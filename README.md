# 钢铁绿色转型指标与副产物闭环

贯通精品钢生产、固废资源化、制氢和环保指标的可追溯数据链。

## 参与方与事实

主要参与方包括钢铁企业管理人员、车间操作人员、环保人员、固废处理企业、能源管理人员。领域资料记录以下已经确认的事实：

- 迁安钢铁产业推进减量提质和精品钢生产
- 当地企业在多道工序应用人工智能并达到绿色工厂标准
- 工业固废资源化和焦炉煤气制氢形成循环经济链条

## 业务约束

- 班次数据冻结
- 指标口径
- 副产物去向
- 职责分离
- 历史报表不可重写

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/steel_context.py` 负责读取和校验这些资料。

## 转型数据服务

`src/steel_ledger.py` 在领域资料之上实现数据服务（纯标准库）：

- 记录产线、工序、原料批次、精品钢规格与产品批次、固废处理、工业副产氢、环保指标口径与合作单位。
- 班次开启即冻结计算口径版本；冻结后数据来源不可变，口径升版不回溯。
- 测量上传按幂等键去重，数值冲突转管理人员人工核对，争议指标不得确认或结算。
- 节能成果必须工艺/算法与环保双签，提交人不得复核自己的数据。
- 检修、检测迟到、副产物改用途只重算相关指标并冲销对应旧结算，其他指标不受影响。
- 已发布报表随发布时快照固化（含指纹），历史口径变更不得重写。
- 任一绿色指标可追溯到原料批次链、工序、处理记录、测量提交人与双签确认。

规则详见 `docs/domain-rules.md`。
